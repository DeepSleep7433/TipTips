# 将 Hermes 作为独立助理引擎

状态：设计基线，连接能力待具体版本验证。

TipTips 的界面、待办、日历、调度、配置和权限由原生 .NET 核心负责，Hermes 通过版本化 Adapter 接入。优先连接独立服务，本机运行时作为可选外部组件，从而保留 Hermes 能力并避免把应用核心组织成 Python 脚本集合。

TipTips 不复刻 Hermes 全部内部循环，也不把 Hermes 私有数据当成自己的数据库。会话与运行使用映射，业务事实仍由 TipTips 持有。Dashboard 管理能力与运行能力分开验证；当前参考 API 声明不支持的管理写入不作默认功能。

代价是需要处理外部引擎版本、认证、生命周期、执行主机和断线对账。工具在 Hermes 主机执行，访问其他电脑必须经过明确授权的执行节点或业务工具入口。
