# 每个个人空间采用单一权威核心

状态：设计基线。

同一个个人空间由一个 CoreHost 拥有正式业务数据库、对象版本与持久调度；多台客户端和执行节点通过接口参与。采用主机本地 SQLite 与事务 Outbox，减少个人部署的外部服务和常驻资源成本。

多主离线同步会显著增加日历冲突、审批、外部副作用和重复调度的复杂度。首版远程离线仅提供缓存阅读和有限捕获，迁移主机必须显式停止旧调度、校验数据并提升权威代次。

代价是主机失联时在线动作不可用，不提供自动主机故障转移。迁移必须退休旧主机并处理旧凭据；权威代次不能单独阻止旧主机直接调用外部平台。数据库不放网络共享；未来多人规模或写入吞吐超出实测边界时再考虑独立数据库与其他可用性方案。
